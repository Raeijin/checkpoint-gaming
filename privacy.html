Privacy notice

Last updated: 19 August 2026.

What Checkpoint Loadout collects

Checkpoint Loadout currently does not run a first-party account system, newsletter signup, comment system or on-site analytics script. The site does not currently ask visitors to submit names, passwords or profile information.

Hosting

The site is hosted using GitHub Pages. GitHub states that when a GitHub Pages site is visited, the visitor’s IP address is logged and stored for security purposes. GitHub’s own privacy terms apply to that processing.

Affiliate and external links

Some pages link to third-party sites such as Amazon or MOZA Racing. Affiliate links can contain referral identifiers so a purchase can be attributed to Checkpoint Loadout. Once you follow an external link, that third party’s privacy and cookie practices apply.

Search performance

The site is registered with Google Search Console so the owner can understand how pages appear in Google Search. No Google Analytics tracking script has been added to the site at this time.

Changes

This notice will be updated if the site adds analytics, advertising, newsletters, contact forms or other features that materially change how visitor data is handled.
